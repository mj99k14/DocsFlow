# DocsFlow Frontend

DocsFlow 문서 라우팅 시스템의 React 프론트엔드.

- **프레임워크**: React + Vite
- **UI**: shadcn/ui + Tailwind CSS
- **배포**: Vercel (https://docs-flow-orcin.vercel.app/)

## 실행

```bash
npm install
npm run dev
```

환경변수 설정 (`frontend/.env`):

```env
VITE_API_URL=http://localhost:8000
```

프로젝트 전체 구조 및 아키텍처는 [상위 README](../README.md)를 참고하세요.
